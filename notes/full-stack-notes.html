HTML

According to mdn the <div> element is a "pure container" meant to group content together in order for it to be styled using the class or id attributes.

CSS

CSS Flexbox

The CSS property display: flex sets an HTML element as a block level flex container which takes the full width of its parent container. Child elements that are inside the flex container are called flex items.

Flex items are subject to change their size and location based upon the size and position of the parent container.

justify-content

justify-content defines how the browser distributes space between and around content items

    Justify content can have the values of below

  • flex-start
  • flex-end
  • center
  • space-between
  • space-around

flex-direction Property

The flex direction property specifies how flex itsm are to be places in the flex container, whether vertically or horizontally. This property determines also whether the flex items appear in order or reverse order. 


        div {
            display: flex;
            flex-direction: row-reverse;
        }
